# Планировщик задач на Go

Это веб-приложение-планировщик задач, написанное на языке Go.  
Позволяет добавлять, редактировать, отмечать выполненные и удалять задачи.  
Поддерживает повторяющиеся задачи по дням, неделям и месяцам.

---

## ✅ Выполненные задания со звёздочкой

1. **Параметризация порта через `TODO_PORT`**  
   Сервер запускается на порту из переменной окружения `TODO_PORT`, по умолчанию — `7540`.

2. **Путь к БД через `TODO_DBFILE`**  
   Файл SQLite-базы данных можно задать через переменную `TODO_DBFILE`, по умолчанию — `scheduler.db`.

3. **Поддержка сложных правил повторения**  
   Реализованы правила:
   - `w 1,3,5` — по дням недели (1=понедельник, 7=воскресенье)
   - `m 4,15` — по дням месяца
   - `m -1`, `m -2` — последний и предпоследний день месяца
   - `m 3 1,3,6` — 3-е число января, марта и июня

4. **Возможность поиска задачи**  
   Реализована возможность поиска задачи на фронтенде:
   - по тексту в наименовании задачи и комментарии
   - на кокретную дату

5. **Аутентификация через пароль**  
   Доступ к приложению защищён паролём из переменной `TODO_PASSWORD`.  
   При входе выдаётся JWT-токен (на основе хэша пароля), хранящийся в куке `token`.

6. **Docker-образ**  
   Проект можно собрать в Docker-образ и запустить с сохранением данных на хосте.

## Для запуска кода проекта локально выполнителе следующие шаги:

1. В текущем репозитории нажмите кнопку "Code", затем "Download ZIP"
2. Распакуйте архив и через командную строку перейдите в директорию проекта
3. Откройте **Git Bash** и выполните команду TODO_PASSWORD=12345 go run main.go - запустится сервер, по умолчанию ":7540" (можно изменить, напримере на ":8080", но тогда далее везде необходимо будет использовать выбранный Вами порт)
4. Для подготовки параметров в файле tests/settings.go необходимо узнать токен, для этого запустите в командной строке код:
```bash
curl -X POST http://localhost:7540/api/signin \
  -H "Content-Type: application/json" \
  -d '{"password":"12345"}'
  ```
5. Ответом будет токен, используйте полученное значение в поле "Token" файла tests/settings.go. Таким образом итоговые параметры:
```go
Port = 7540
var DBFile = "../scheduler.db"
var FullNextDate = true
var Search = true
var Token = "...."
```
6. После заполнения всех параметров запустите все тесты из корневой папки проекта. Введите в командной строке:
```bash
go test ./tests
  ```
8. Для сборки Docker-образа введите команду:
```bash
docker build -t todo-server .
```
8. Для запуска Docker-контейнера откройте **PowerShell** перейдите в директорию проекта и введите команду:
```powershell
docker run -d \
  --name todo-app \
  -p 7540:7540 \
  -e TODO_PASSWORD=12345 \
  -v ${PWD}/scheduler.db:/app/scheduler.db \
  todo-server
```
